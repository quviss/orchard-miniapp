# Orchard — демонстрационный каталог техники

Статический Telegram Mini App на HTML/CSS/JavaScript. Заказы, платежи и обращения никуда не отправляются. Серверная часть и реальные данные магазина не подключены.

## Локальный запуск

Из папки проекта:

```sh
python3 -m http.server 4173 --bind 127.0.0.1
```

Откройте `http://127.0.0.1:4173/`. Редактор каталога — `http://127.0.0.1:4173/admin.html`, также доступен по ссылке внизу витрины. Сборка и установка пакетов не нужны. Для фото устройств, шрифта Inter и Telegram SDK требуется интернет; при сбое загрузки фото повторяется запрос и используется другой исходный ракурс того же цвета. Фотографии не заменяются рисованными устройствами. SVG-иллюстрации используются только для товаров, у которых фото изначально отсутствуют. Исходные снимки сохранены без изменения; локальные копии позволяют при отображении сделать внешний белый фон прозрачным. Белые подложки карточек сохраняются в обеих темах.

## Что добавлено

- Компактная чёрно-белая витрина со светлой и тёмной темами. Иконка солнца/луны вместо «Демо» переключает тему; выбор сохраняется в браузере, пока пользователь его не изменит. До первого выбора применяется тема Telegram/системы.
- Поиск с русскими названиями, фильтры по категории, цене, памяти, SIM, наличию и скидке. Условия цены, памяти и SIM относятся к одной комплектации; карточка открывает найденную версию.
- Избранное, недавно просмотренные модели, сравнение до трёх моделей одной категории и режим «Только различия». Фото сравнения имеют компактную явно заданную высоту (без растяжения Safari). Таблица помещается в ширину экрана без горизонтальной прокрутки; «Новые открытия» и история — ровная сетка.
- Основная кнопка карточки — «В корзину»; сравнение перенесено в компактную иконку рядом с избранным. Над кнопкой показана добавляемая комплектация.
- Локальная админка: создание, редактирование, дублирование и скрытие товаров; варианты и цены, цвета и остатки, характеристики и фото по ссылке.
- Импорт и экспорт JSON каталога версии 1, восстановление исходных данных с подтверждением. Невалидный импорт не заменяет текущие данные. При ошибке записи редактор сообщает, что данные не сохранились.

## Где хранятся изменения

Каталог редактора хранится в `localStorage` под ключом `orchard.catalog.v1`. Избранное, сравнение, корзина и история просмотров также сохраняются в браузере. Это редактор макета без входа и без сервера. Его правки видны только в том же браузере и на том же origin (протокол + адрес + порт). Safari, Telegram WebView и Chrome имеют отдельные хранилища. Правки не меняют GitHub и не становятся видны другим посетителям.

Чтобы перенести каталог на другое устройство, экспортируйте JSON и импортируйте его в редакторе. Экспорт включает сохранённые товары; сначала сохраните открытый черновик. Для публикации общего каталога потребуется отдельно обновить исходные данные проекта или добавить сервер — в этом макете это не выполняется.

Исходные модели находятся в `js/data.js`, URL фотографий — в `js/photos.js`. Остатки в макете общие для всех комплектаций одного цвета. При скрытии/удалении варианта из каталога соответствующая старая позиция корзины удаляется, а при перестановке цветов/версий выбранные позиции сохраняются по названиям.

## Telegram

Подключение `telegram-web-app.js` сохранено. `js/telegram-bridge.js` изолирует необязательные методы клиента: ready/expand, BackButton, смену темы, safe area и обновления viewport. Встроенная кнопка возврата скрывается только после успешного подключения и вызова нативной. Неподдерживаемые методы не блокируют открытие каталога.

Safe area применяется по данным SDK с CSS-fallback. Вёрстка не принуждает полноэкранный режим и не запрещает масштабирование. Локальная админка не выполняет авторизацию и не использует Telegram initData для выдачи прав.

Перед заменой действующего Mini App проверьте HTTPS-предпросмотр на настоящем клиенте Telegram iOS/Android: переходы каталог → товар → корзина → пример оформления, возврат из сравнения, светлую/тёмную тему, открытие клавиатуры и нижние отступы. Safari в симуляторе проверяет iOS-вёрстку, но не заменяет Telegram WebView.

Официальная документация, использованная для проверки совместимости: https://core.telegram.org/bots/webapps

## Проверки

Нужен Node.js 18+ (без npm-зависимостей):

```sh
node --test tests/*.test.cjs
```

Тесты проверяют подбор конфигураций, русские запросы, сортировку, импорт, ошибки хранилища, сохранение вариантов корзины после правок, сравнение и запуск фактического приложения с отсутствующим/частичным/современным Telegram SDK. Заглушки SDK не являются тестом в реальном Telegram.
